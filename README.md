# CocoScrapers Kodi repository

This repository is a custom build based on the original CocoScrapers module by CocoJoe.

It adds authenticated torrent scraping support for:

- TreZzoR (`tracker.czech-server.com`)
- SkTorrent (`sktorrent.eu`)

Install `repository.cocoscrapers.zip` in Kodi.

Kodi file source: `https://pepe424.github.io/repository.cocoscrapers/`
